# Rainywithin's VPM Repository

This is a VRChat Creator Companion (VCC) repository hosting custom Unity Editor tools and avatar utilities.

### How to Install
Click the button below to automatically add this repository to your VCC:

[![Add to VCC](https://vcc.docs.vrchat.com/img/badges/add-to-vcc.svg)](vcc://vpm/addRepo?url=https://URektMe.github.io/rainywithin-vpm/index.json)

*(If the button doesn't work, open VCC -> Settings -> Packages -> Add Repository, and paste the following URL: `https://YOUR_GITHUB_USERNAME.github.io/rainywithin-vpm/index.json`)*

### Included Packages
* **Outfit Linker:** A Unity Editor tool that automatically generates VRCFury toggles, organizes meshes, and links avatar outfits.
